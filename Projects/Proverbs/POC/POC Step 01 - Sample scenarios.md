# POC Step 01 — Sample scenarios

Step 1 of [[_POC MOC|the POC plan]]: twenty scenarios written the way a user would say them, each with the tags it would need and the passages already known to speak to it. Ten are answerable from the step 2 slice (chapters 3 and 10); ten are not, to catch false hits. Suggested 2026-11-03 as a starting set for Doug to replace with his own. Tags use the six user-facing axes from [[Categorization Scheme]]; values not in the draft scheme are marked with an asterisk. Passage references are from memory of the book and must be checked against the BSB text in step 2.

## Values not in the draft scheme

Situation values the scenarios needed that the draft axis table does not list: paying what is owed, a setback, a conversation I regret, work I avoided, conflict with family, constant arguing, being provoked, offered a bribe, passing something on. Whether these become values, fold into existing ones (being provoked into conflict with a neighbor; constant arguing into conflict with family), or are keywords instead is a step 2 question.
